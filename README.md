# The One-Liner Groan-Off

An entry for the [make.fun bounty "The One-Liner Groan-Off"](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5): a program that writes one original one-line dad joke to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes the entry deterministically (two runs produce byte-identical output) and refuses to write anything that would fail the gate (1–140 characters, not only white space).

## The joke

> I asked my son why he put his shoes in the freezer — he said he wanted cold feet before asking me for money.
